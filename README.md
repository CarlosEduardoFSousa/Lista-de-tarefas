# 🏫 Sistema de Lista de Tarefas (To-Do List) - UniVap

Este projeto é uma solução voltada para a produtividade e organização pessoal e acadêmica, permitindo o gerenciamento eficiente de tarefas diárias, prazos de entrega e compromissos escolares. O sistema foi estruturado para auxiliar os estudantes do Colégio Univap a manterem o foco e o controle sobre suas entregas pedagógicas.

## 🚀 Funcionalidades

* **Gerenciamento de Tarefas:** Cadastro de novas obrigações com títulos, descrições detalhadas e prazos.
* **Controle de Status:** Opção de marcar tarefas como pendentes, em andamento ou totalmente concluídas.
* **Filtros e Visualização:** Organização visual rápida para identificar prioridades e atividades atrasadas.
* **Remoção e Atualização:** Sistema para edição de informações e exclusão de itens que já foram cumpridos.
* **Persistência de Dados:** Armazenamento seguro da lista de atividades para que nenhuma informação seja perdida ao fechar o sistema.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** C# / Java / JavaScript *(Nota: Ajuste para a linguagem principal usada no seu projeto)*
* **Interface:** Interface Gráfica Intuitiva (UI)
* **Ambiente de Desenvolvimento:** IDE de Desenvolvimento
* **Conceitos:** CRUD (Create, Read, Update, Delete), Manipulação de Eventos e Lógica de Programação.
